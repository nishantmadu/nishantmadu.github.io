# Data Engineering · A Visual Study Guide

This guide contains 354 lessons, 43,279 lesson words, and 26 interactive diagrams for Fundamentals of Data Engineering by Joe Reis and Matt Housley (O’Reilly Media, 2022). It covers 11 chapters and 2 appendices.

Open index.html through GitHub Pages to study the guide. The existing gh-pages branch publishes this folder beside the portfolio. All guide assets use relative paths.

The lessons use ASD-STE100-inspired English. They simplify the indexed topics and do not replace every detail in the original book. This is not a certified ASD-STE100 document.

To check the source, choose Original pages and select your own PDF. The file stays in your browser. No source PDF is published in this repository. Source links match the original 445-page file; for the main numbered text, PDF page = book page + 25.

Use Diagram + lesson for interactive examples, Read this chapter for all topic explanations and full-text search, and the underlined terms for definitions.

All original authored chapter files are preserved. Programmatic checks covered every lesson and diagram, navigation, search, example calculations, local PDF handling, source-page links, and asset paths.

For future updates, change the files in this folder and commit to the gh-pages branch. The portfolio files at the repository root are separate from this guide.
